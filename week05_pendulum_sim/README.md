## 三、实验目标

以单摆（Simple Pendulum）为对象，完成从物理建模到数值仿真的完整闭环：

1. 建立单摆运动的微分方程模型（小角度近似 → 完整非线性模型）
2. 实现数值积分求解（Euler / 改进 Euler / RK4 对比）
3. 可视化摆角、角速度随时间的变化，并做能量守恒验证
4. 记录人机协作过程：AI 生成代码与人工校核的分工与差异
