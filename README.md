## 二、仓库简介

本仓库是本人参加《人机协同编程》课程期间的**个人作品集主仓库**，用于统一存放全学期 16 周的实验代码、实验报告、数据与项目成果。

- 每周实验独立成目录，命名格式：`（第NN周）实验主题`
- 每周目录内含该周源代码、实验报告（`README.md`）与运行说明
- 所有实验过程通过 Git 提交记录留痕，可完整回溯学习轨迹

```bash
# 2. 进入仓库

```
